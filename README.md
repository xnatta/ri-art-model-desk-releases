# Ri-Art Model Desk

Windows x64 installers and the public update channel.

Download the latest Setup.exe from Releases, install it, paste a Sketchfab model link and choose an output folder. The runtime is bundled. Thai and English interfaces are available.

Use models you have permission to download and use. Availability depends on Sketchfab and the upstream converter. This installer is currently unsigned.

Contains sfrip 0.1.0 under MIT License. https://github.com/Corpocore/sfrip

Design workflow uses Unslop by Damir Sokolovsky, CC BY 4.0. https://heydamir.design/unslop

SHA256SUMS.txt verifies the downloaded installer. latest.yml and the blockmap support in-app updates. Settings and model output are stored outside the installation directory.
